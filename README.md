Lumenify – AI-Powered Quiz Generation System
Developed a full-stack web application that utilizes Large Language Models (LLMs) to automate educational content creation.

AI Integration: Integrated the Gemini AI API to analyze user-uploaded documents and generate context-aware quiz questions and answers, demonstrating practical experience with prompt engineering and LLM responses.

Full-Stack Development: Built a responsive frontend using Vue.js and Tailwind CSS for dynamic user interaction, coupled with a PHP and MySQL backend for secure data management and retrieval.

System Architecture: Designed the system to handle file parsing and data formatting, ensuring high accuracy in the generated output—a key skill for data quality and annotation tasks.
